# msfs2xp Converter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust CLI that converts MSFS 2020/2024 airport packages (compiled BGL or SDK XML) into X-Plane 12 `apt.dat` scenery packs.

**Architecture:** Layered pipeline: package discovery → BGL/XML parsers producing raw records → sim-neutral `model::Airport` → conversion modules producing typed `xplane::Apt` rows → writer/validator/preview. Every parser is bounds-checked and size-driven so unknown or newer record layouts degrade to warnings, never crashes.

**Tech Stack:** Rust 2021 (stable 1.97), clap 4, roxmltree, geo, rayon, indicatif, tracing, serde/serde_json, walkdir, thiserror/anyhow, insta (dev).

**Spec:** `docs/superpowers/specs/2026-09-12-msfs2xp-converter-design.md`

## Global Constraints

- Crate name `msfs2xp`, binary `msfs2xp`, Rust edition 2021, no `unsafe`.
- No panics on any input (§5.1): all reads bounds-checked, per-airport `catch_unwind`.
- Output apt.dat version line: `1200 Generated by msfs2xp <version>`; CRLF line endings, first line `I`.
- Git: author `vihaan2012-cmyk <vihaan2012-cmyk@users.noreply.github.com>`, no co-author trailers.
- Quality gates before a task is "done": `cargo test`, `cargo clippy -- -D warnings`, `cargo fmt --check`.
- Real MSFS fixtures live at `D:\Microsoft Flight Simulator 2020\Microsoft Flight Simulator 2020 Packages\Official\OneStore` (env `MSFS2XP_FIXTURES`), used only by `#[ignore]` tests.
